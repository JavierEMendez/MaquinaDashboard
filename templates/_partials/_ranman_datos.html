Upload the monthly package
Pick a whole month folder from Archivos Ranman\<year>\<n>_<Month>, or any files. Files are recognised by name; backups, scenario sub-folders and draw slips are left out. Each file is sent on its own, checked against its own totals and logged below. AAA, Flujo y PLP, Cuadro de Riesgos, Edo. Resultados, Breakeven, Pipeline, the Sábana Operativa and the BP models are read today; the rest are recorded as received. A month with its BPs is some 150 MB, so a whole folder takes a few minutes.

The script runs on a computer that has the Ranman OneDrive folder synced. It walks the last few month folders, sends only new or changed deliverables to /api/ranman/package, and remembers what it sent.
  1. Pick a long random token, set it as RANMAN_SYNC_TOKEN on Railway, and set the same value on the computer that will run the sync.
  2. Set RANMAN_SYNC_URL on that computer to {{ pk.sync.url }}.
  3. Try it: 
    python tools/ranman_sync.py --dry-run
    then without --dry-run to send.
  4. Schedule it daily, for example with Windows Task Scheduler running the same command.
